The documentation in this tree is in plain text files and can be viewed
using any text file viewer.

It uses `ReST`_ (reStructuredText), and the `Sphinx`_ documentation system.

To build an HTML version of the docs:

* Install Sphinx (using ``python -m pip install Sphinx`` or another method).

* In this directory, type ``make html`` at a shell prompt.

The built documentation in ``_build/html/index.html`` can then be read in a
web browser.

.. _ReST: https://docutils.sourceforge.io/rst.html
.. _Sphinx: https://www.sphinx-doc.org/
